# Contributing

Issues and pull requests are welcome. For a task or adapter change, include the corresponding interface, hardware/session fields, and event-channel documentation. Keep scoring deterministic and preserve raw evidence in MCAP so results can be rescored.

Before proposing a change to a benchmark definition, explain how already-collected runs would remain comparable. A task definition must not be adjusted after seeing baseline results; changes that affect scoring should use a new protocol version.

Do not commit API keys, private robot access credentials, or unreviewed session recordings. Use the Apache-2.0 license for contributions to this repository.
